# GeoRisk Studio (Static Prototype)

Standalone static HTML prototype for an environmental hazard / risk comparison tool.

## Pages

- `index.html` — Dashboard / landing page
- `search.html` — Region search
- `compare.html` — Compare two regions side by side
- `compareby.html` — Alternative comparison layout (by-criteria)

## Usage

Open any `.html` file directly in a browser. No build step or dependencies required.
